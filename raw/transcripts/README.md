# raw/transcripts/

Verbatim transcripts of founder brainstorms and recorded working sessions — the **primary artifact**. Digested, opinionated write-ups live in [`../../brainstorming/`](../../brainstorming/) (or `strategy/`) and **cite back here** rather than copying, so the digest can be reshaped without losing the source words.

This is distinct from [`../../meetings/`](../../meetings/) (external calls/meetings → digest + collapsed transcript, with downstream propagation) — `transcripts/` is for internal founder brainstorming sessions whose verbatim text we want preserved alongside the brainstorm digest.

**File naming:** `YYYY-MM-DD-<participants-or-topic-slug>.md` — verbatim text, lightly segmented for navigation only (never reworded). Carries `type: source` + a `description:` so it appears in the parent INDEX.

Cite from elsewhere with the relative path, e.g. `[[../raw/transcripts/YYYY-MM-DD-topic-slug-brainstorm]]`.
