# raw/events/

Founder-authored binaries for events **we run** — budget frameworks, sponsorship decks, run-of-show documents, prize-pool models.

Distinct from:

- [`../pitchdecks/`](../pitchdecks/) — decks pitching the project itself
- [`../../competitions/`](../../competitions/) — programs **we enter**, not events we host

## Convention

Same as the parent [`raw/README.md`](../README.md): each binary that gets cited often gets a same-basename `.md` sidecar with `type: source`, a `description:` in frontmatter, and a section-by-section breakdown so an agent can answer "what does the budget say about security?" without opening the binary.

Sidecars record what the document **says**. Our positions on it live in [`../../strategy/`](../../strategy/) or [`../../brainstorming/`](../../brainstorming/).
